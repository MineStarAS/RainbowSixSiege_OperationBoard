## | Description

A program for game strategy and play feedback.

## | HotKeys

* [Numpad 1 ~ 9] Select Sketch Color.
* [Q, W, E, A, S, D] Select Sketch Mode.
* [1 ~ 5] Select Floor.


* [Ctrl + Z] Undo Sketch.
* [Ctrl + Shift + Z] Redo Sketch.
* [Ctrl + D or Del] Delete Selected Icon.
* [Ctrl + C] Copy Selected Icon.
* [Arrow Key] Move Map Image.

## | Mouse Control

### # Map Control

* [Wheel Scroll] Zoom In/Out.
* [Click + Drag] Draw Sketch.
* [Double Click + Drag] Move Map Image.

### # Icon Control

* [Click] Select Icon.
* [Click + Drag] Move Icon.
* [Double Click] Open Option Panel.
